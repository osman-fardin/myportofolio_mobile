# Visual Assets

Gambar Fardin.JPG, about-cloudscape.jpg, dan server-racks.webp disalin tanpa
perubahan dari direktori static/img pada
[repo web portofolio](https://github.com/osman-fardin/myportofolio/tree/main/static/img).
Foto dan isi profil mengikuti portofolio pemilik yang sama.

SpaceGrotesk.ttf berasal dari
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/spacegrotesk)
dan disertakan bersama [SIL Open Font License 1.1](fonts/OFL.txt).
Font tidak diubah. Lisensinya juga didaftarkan melalui LicenseRegistry Flutter.
